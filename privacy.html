Privacy Policy

Last updated: 20 November 2026

LoopFrenzy Control Room ("the tool") is a private, single-user application operated by Haytham Fourati, the owner of the LoopFrenzy YouTube channel. It runs only on the owner's own computer. This policy explains what data the tool accesses and what it does with it.

YouTube API Services

The tool uses YouTube API Services (the YouTube Data API and the YouTube Analytics API). By using the tool, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Data the tool accesses

After the channel owner signs in with Google OAuth, the tool accesses only the owner's own channel:

  • Channel information: the channel ID and name, to confirm it is connected to the right channel.
  • Video information: the IDs, titles, publish status and public view and like counts of the channel's own videos, to confirm each upload is live.
  • Channel analytics: views, watch time, average view duration, average percentage viewed and traffic sources for the channel's own videos.
  • Uploads: video files, titles, descriptions and tags that the owner has prepared, sent to the owner's channel.

The tool requests these Google OAuth scopes: youtube.upload, youtube.readonly and yt-analytics.readonly. It does not access any other user's account, channel or private data.

How the data is used

Only to upload the owner's own Shorts on schedule, confirm they went live, and show the owner a dashboard of their channel's performance. The data is not sold, shared with, or disclosed to any third party, is not used for advertising, and is not combined with data from other sources.

Storage and security

The OAuth tokens and the retrieved data are stored only on the owner's computer, in files readable only by the owner's user account. They are not uploaded to any server. Data retrieved from YouTube API Services is refreshed or deleted within 30 days, except public statistics (such as view counts), which are kept for at most the period allowed by the YouTube API Services Developer Policies.

Cookies

The tool does not place cookies or trackers on any device. This website does not use cookies or analytics.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. When access is revoked or the tool is no longer used, the stored tokens and all data retrieved through YouTube API Services are deleted from the owner's computer within 7 days. A deletion request can also be sent to the contact address below and will be completed within 7 days.

Changes

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
